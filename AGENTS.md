

## DROP 0003 microblock implementation rules

- Read `packs/microblock/providers/` before assuming provider capabilities.
- Use the microblock translation plan; do not blanket-convert a module.
- Default to TIER 1–2. TIER 3 requires visible benefit; TIER 4 requires focal justification.
- Preserve functional vanilla blocks by default.
- Preserve connectors, player clearance and approved vanilla silhouette anchors.
- Do not use one-cell random surface noise as “detail.”
- For monumental ceilings/roofs, keep broad quiet fields and only refine major joints/trusses.
- Treat provider material counts as snapshots; validate actual supported states at compile/export time.

# Vanilla Build Language

Stage A creates a complete, high-quality vanilla Minecraft build before microblock translation.

## Required hierarchy

PRIMARY massing → SECONDARY structure → TERTIARY trim/furniture → MICRO clutter.

A build may be monumental while still respecting player scale. Detail should concentrate at transitions, focal points and eye level, not uniformly across every surface.

## Pack-driven workflow

1. Normalize to supported vanilla blocks/states.
2. Lock circulation and connectors.
3. Establish scale and primary architecture.
4. Select architecture families from `packs/vanilla/architecture/`.
5. Apply builder techniques from `packs/vanilla/techniques/`.
6. Select palette roles from `packs/vanilla/palettes/`.
7. Furnish using furniture packs and contextual clusters.
8. Landscape using vegetation families with mandatory variation.
9. Add decor and lighting with negative-space limits.
10. Review from player eye level before microblock analysis.

## Non-negotiable rules

- Complexity is not detail.
- Repetition must have hierarchy and variation.
- Important walls need depth.
- Roofs should read as a few strong structural ideas.
- Never randomize a palette merely to add texture.
- Never let ornament block circulation.
- Never stamp the same tree/furniture module on a visible grid.
- Preserve quiet surfaces around focal detail.

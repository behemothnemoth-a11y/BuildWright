# Architecture Packs

Architecture is grouped by structural role: arches, piers, walls, facades, roofs, ceilings, stairs, windows, portals, galleries, railings, fireplaces, chimneys, towers, bridges, floors, trim, foundations and dormers/gables.

Each family contains several profiles so a project can establish rhythm without copy-paste fatigue.

Use major families to solve structure first. Decorative architecture should reinforce the structural reading rather than competing with it.

# Build Pipeline

## Stage A — Vanilla

1. Register source/reference.
2. Establish player scale and envelope.
3. Build primary architecture.
4. Resolve circulation and connectors.
5. Apply builder-technique pass.
6. Apply controlled palette/gradient pass.
7. Add furniture, decor, lighting, and vegetation packs.
8. Review from player eye level.
9. Export and validate vanilla schematic.
10. Mark REVIEW_CANDIDATE.
11. Approve only after in-game review.

## Stage B — Microblock

1. Freeze the approved vanilla master.
2. Identify conversion candidates.
3. Classify each candidate.
4. Choose detail tier.
5. Convert only approved targets.
6. Recheck circulation and silhouette.
7. Validate export.
8. Compare vanilla and microblock editions in-game.

## Iteration loop

```text
reference
→ build candidate
→ schematic
→ Minecraft test
→ screenshot/video
→ critique
→ bounded refinement
→ candidate
```

Prefer bounded module refinement over rebuilding the entire project for every change.

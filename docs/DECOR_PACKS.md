# Decor Packs

Decor is grouped into contextual clusters: books/papers, lighting objects, paintings, armor/trophies, textiles, pottery, clocks/instruments, food, workshop tools, shelf clutter, statues, plants, signage, occult/fantasy detail and drapery.

Decor density should fall away from focal points. Leave empty shelves, blank wall fields and clear table surfaces where they improve readability.

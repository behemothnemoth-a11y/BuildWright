# Material & Gradient System

Palettes define semantic roles, not random weighted bags.

## Typical roles

- shadow / recess
- primary body
- exposed highlight
- trim
- weathering
- metal / glass / foliage accent

## Placement logic

Use darker/rougher materials in recesses, damp zones and heavy bases. Use cleaner/lighter materials on exposed trim, upper edges and intentional focal points. Weathering belongs where water, foot traffic, neglect or repairs make sense.

A good gradient is spatially explainable when viewed without knowing the palette recipe.

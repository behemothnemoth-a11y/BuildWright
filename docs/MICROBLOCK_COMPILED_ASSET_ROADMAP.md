# Compiled Microblock Asset Roadmap

DROP 0003 defines parametric families and translation contracts; it does not ship hundreds of opaque precompiled sculptures.

Future compiled-library drops should add tested `.litematic`/provider-native fixtures for the most valuable variants while preserving the recipe IDs in this catalog. Priority order:
1. arches / columns / capitals;
2. railings / stairs / windows;
3. hammerbeam and roof joinery;
4. furniture contour library;
5. mechanical detail;
6. hero decor and sculpture.

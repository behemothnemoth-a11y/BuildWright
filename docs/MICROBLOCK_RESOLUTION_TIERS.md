# Microblock Resolution Tiers

Tiers describe **authoring density**, not a different physical grid. Astra still stores 16×16×16 cells; BuildWright tells authors which cell increments should dominate.

- TIER 1: prefer 4-cell increments.
- TIER 2: prefer 2-cell increments.
- TIER 3: 1-cell details allowed but localized.
- TIER 4: 1-cell hero sculpture with explicit focal justification.

The eye should not be able to infer the 16-cell grid everywhere. Broad surfaces remain broad.

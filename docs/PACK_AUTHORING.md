# Pack Authoring

A pack is a reusable family of build techniques or assets.

## Rules

- Packs should contain variants, not one endlessly repeated prefab.
- Packs must declare stage: vanilla, microblock, or both.
- Packs must declare intended scale and categories.
- Packs should state when not to use them.
- Architectural packs must not silently break circulation.
- Decorative packs should support rotation / variation / asymmetry where possible.

Use `packs/templates/PACK_TEMPLATE.md` when adding a family.

# Site Assembly

The project compiler adds a lightweight site language around assembled buildings.

## Current site operations

- configurable ground plane
- project margin
- deterministic orthogonal paths
- style-driven ground/path defaults
- sparse edge features such as hedge, wall or hardscape cues
- site-character metadata
- vegetation-profile intent

Current site characters include formal, courtyard, garden, integrated landscape, lush integrated, forest, mountain, farm, desert, dense urban, hardscape, service yard, platform, temple garden, monumental, overgrown and submerged.

Site compilation happens after building assembly and before final coordinate normalization.

The site layer is intentionally conservative. It establishes a coherent pad/circulation context without pretending to replace a dedicated terrain/landscape compiler.

Future work will attach vegetation fixtures, roads, plazas, walls, fences, retaining structures, water features, terrain gradients and reference-driven real-world site geometry.

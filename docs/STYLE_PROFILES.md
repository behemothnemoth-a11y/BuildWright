# Style Profiles

Style profiles are weighting presets for selection. They reference palettes, architecture families and density targets; they do not lock a build into a rigid template.

Profiles currently cover Gothic manor, Victorian estate, medieval village, dark fortress, elven fantasy, dwarven citadel, rustic tavern, industrial/steampunk, modern luxury, Mediterranean/coastal, Japanese traditional, ancient ruin, cave megastructure, urban Gothic, haunted mansion and garden estate.

# Vanilla → Microblock Mapping

`packs/microblock/translation_map.json` maps vanilla family vocabulary from DROP 0002 to one or more refinement families.

A mapping means **possible refinement**, not mandatory conversion. Candidate analysis can still return KEEP_VANILLA or DO_NOT_CONVERT based on function, viewing distance, performance and composition.

Typical examples:
- vanilla arches → arch refinement + tracery;
- vanilla columns/piers → shaft contour + capitals/bases;
- vanilla stairs → stair trim + banisters;
- vanilla roofs/ceilings → hammerbeam details, ribs, joints;
- vanilla furniture → contour families;
- vanilla trees → optional branch/root refinement only;
- vanilla lab/workshop → mechanical frames, pipes, grilles and consoles.

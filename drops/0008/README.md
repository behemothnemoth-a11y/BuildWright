# DROP 0008 — Universal Style & Exterior System

Major project-neutral architecture update.

## Added

- 35 universal style profiles across 14 architectural families
- semantic material-role system
- primary/secondary style blending
- facade-zone language: hero / primary / secondary / service / courtyard / blind
- expanded facade rhythms, depth biases and ornament controls
- expanded window-language compiler
- expanded roof-language compiler including shed, butterfly, sawtooth, pagoda/tiered, dome, vault, terrace and ruin modes
- site-character language
- 21 committed cross-style showcase compiles
- style registry generator and validation
- living CATALOG.md + machine-readable catalog/catalog.json

## Principle

BuildWright is not a Wayne Manor generator. Named projects are regression/use-case projects. Universal compiler logic must remain usable across historical, modern, industrial, cultural, speculative, fantasy, ancient, organic, real-world and experimental builds.

## Maturity

Style showcases are offline regression outputs. They remain LIVE_GAME_PENDING until reviewed in Minecraft.

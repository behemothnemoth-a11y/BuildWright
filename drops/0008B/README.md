# DROP 0008B — Visual Catalogue

Picture-first catalogue follow-up for BuildWright 0.8.

## Added

- root VISUAL_CATALOG.md entry point
- full fixture gallery using the 64 existing compiled-fixture previews
- deterministic isometric renderer for compiled Litematics
- automatic cutaway rendering for room/module interiors
- 7 rendered composition examples
- 3 rendered whole-building regression projects
- 37 rendered style showcases covering every core style plus two blends
- fixture, room, project and style gallery pages
- five overview/contact-sheet images
- machine-readable visual_manifest.json
- visual catalogue coverage checks in normal repository validation

## Important

Generated isometric images show the real compiled block geometry with simplified material colors. They are not Minecraft screenshots, shader renders or concept art.

## Maturity

The catalogue is a visualization layer. It does not promote LIVE_GAME_PENDING artifacts to APPROVED.

# DROP 0011 — Style-Specific Finish & Reference Fitting

BuildWright 0.11.0 adds architectural-family finishing and measurable reconstruction constraints.

## Added

- 14 project-neutral style-family finishing grammars
- family-specific facade bands, corner structure, eaves, lighting rhythm, planting, service runs, parapets and finials
- automatic style-family finish for vanilla-finished projects unless explicitly disabled
- semantic material-role inheritance from active style profiles
- 14 committed pure-vanilla style-family finish regression projects
- measured project-size constraints
- measured module origin and size constraints
- named-port world-coordinate constraints
- facade length and height constraints
- advisory reference-fit mode
- strict fail-closed tolerance mode
- optional measured-origin injection
- reference-fit provenance in canonical source and manifests
- style-finish provenance in canonical source and manifests

## Regression

The classical style-family regression exercises strict zero-tolerance reference fitting.

All 14 style-family finish examples remain pure vanilla and are scanned for Astra namespace leakage.

## Maturity

A successful style finish/reference-fit compile is still an offline result. Minecraft/player-eye review remains mandatory.
